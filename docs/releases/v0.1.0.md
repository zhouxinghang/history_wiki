# 历史 Wiki v0.1.0 发布说明

这是首个单实例生产候选版本：一个非 root 容器同时提供 SPA 与 API，一个 PostgreSQL 17 实例保存数据；数据库迁移通过独立命令显式执行。发布步骤、Secret、健康检查、指标及限流见 [生产运行手册](../operations/production.md)。

## 数据风险（发布前必须确认）

- 本版本没有数据库备份、恢复流程或 PITR；数据库实例或持久卷损坏可能永久丢失全部历史事件、活动草稿、事件版本、规范实体、账号、Session 和审计记录。
- 事件版本不是数据库备份，不能处理实例损坏。
- 本版本没有高可用、冗余实例或自动故障转移，服务或数据库故障期间不可用。
- 在录入不可替代内容前，必须重新评审 ADR-0009，并完成备份、恢复演练与高可用目标。

生产迁移从空库开始，不包含演示数据；10 万条性能数据仅由显式、破坏性的专用验证命令生成在名称含 `test` 或 `perf` 的数据库中。
